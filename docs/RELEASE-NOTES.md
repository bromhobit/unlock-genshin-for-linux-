# Выпуск 0.2.0 (preview)

Первый готовый пакет `genshin-fps-linux` для Arch Linux и CachyOS. Он устанавливает CLI, библиотеку preload, GTK4 GUI, пункт меню, значок и лицензию. Саму игру и Wine/Proton пакет не содержит.

В комплект релиза входят пакет `.pkg.tar.zst` и `install-genshin-fps.sh`. Дополнительный файл с контрольными суммами для установки не требуется. Для сборки из исходников доступны `scripts/build-arch-package.sh`, архив исходников и `PKGBUILD` с его SHA256.

Пользовательская установка теперь имеет парный `uninstall-user.sh` и значок приложения. Установки в системный и домашний каталоги следует использовать по отдельности.

**Проверено:** Rust-тесты, тесты команд GUI, компиляция Python, сборка Arch-пакета, содержимое пакета, тест загрузки preload в отдельный Linux-процесс. **Не проверено:** изменение FPS в реальной игре и прохождение `LD_PRELOAD` через Steam/Proton. Пользователь принимает риски, связанные с условиями игры.
