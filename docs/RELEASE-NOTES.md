# Выпуск 0.2.3 Preview 1

Добавлена короткая команда `gfps %command%` для Steam: системный пакет устанавливает `/usr/bin/gfps`, пользовательский установщик — `~/.local/bin/gfps`. Команда фиксирует цель 120 FPS, передаёт аргументы через `exec` и сохраняет существующий `LD_PRELOAD`.

Библиотека размещается при запуске игры в пользовательском каталоге под именем с SHA-256 содержимого. Повторные запуски используют проверенную копию; обновление не заменяет файл, который может использовать текущий процесс. `steam-short-options` печатает короткую абсолютную строку без размещения библиотеки.

GTK4 приложение теперь только показывает и копирует параметры запуска Steam. Оно не запускает игру и не содержит выбора FPS или Wine. Пользовательская установка отказывается заменять чужой `gfps`, включая существующий ручной wrapper.

Пакет для Arch/CachyOS, скрипт установки, архив исходников и `PKGBUILD` входят в выпуск. Отдельного `SHA256SUMS` нет. FPS unlock прежней версии 0.2.2 подтверждён пользователем в реальном Genshin Impact через Steam/Proton на Zenith. Для нового системного пути нужна проверка в конкретной среде Steam. Модификация памяти может быть обнаружена античитом; скрытность не гарантируется.
