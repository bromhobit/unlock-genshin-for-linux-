# Выпуск 0.2.4 Preview 1

GTK4 приложение позволяет выбрать лимит 10–1000 FPS (по умолчанию 120), показывает короткую команду Steam и копирует строку для текущего значения. Оно не запускает игру и не размещает библиотеку при предпросмотре.

`genshin-fps steam-short-options 144` печатает абсолютную команду `/usr/bin/gfps --fps 144 %command%` для системного пакета. Без FPS выводится прежняя команда `gfps %command%`. `gfps --fps 144` передаёт игре выбранную цель и все аргументы через `exec`, сохраняя существующий `LD_PRELOAD`; без `--fps` цель остаётся 120. Значения вне 10–1000 и неверные параметры отклоняются до размещения библиотеки.

Библиотека размещается только при запуске команды игры в пользовательском каталоге под именем с SHA-256 содержимого. Повторные запуски используют проверенную копию; обновление не заменяет файл, который может использовать текущий процесс. Пользовательская установка по-прежнему отказывается заменять чужой `gfps`, включая существующий ручной wrapper.

Пакет для Arch/CachyOS, скрипт установки, архив исходников и `PKGBUILD` входят в выпуск. Отдельного `SHA256SUMS` нет. FPS unlock версии 0.2.2 подтверждён пользователем в реальном Genshin Impact через Steam/Proton на Zenith. Для нового системного пути нужна проверка в конкретной среде Steam. Модификация памяти может быть обнаружена античитом; скрытность не гарантируется.
