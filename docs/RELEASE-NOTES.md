# Выпуск 0.2.2 Preview 1

Исправлена обработка больших PE-образов: прежний предел 256 МиБ не пропускал текущий GenshinImpact.exe размером 432 МиБ. Сканер читает только отображённые области небольшими блоками, проверяет заголовки, секцию il2cpp, цепочку переходов и доступность целевого адреса для записи. Добавлен поиск анонимного PE-отображения Wine только в процессе с именем игры.

`steam-options` теперь копирует библиотеку в каталог данных пользователя перед выдачей параметров Steam, чтобы путь был доступен внутри pressure-vessel. Существующий `LD_PRELOAD` сохраняется. `GENSHIN_FPS_LOG=1` записывает ограниченный журнал процесса в каталог состояния пользователя.

Пакет Arch/CachyOS, GUI и пользовательская установка сохранены. В комплект релиза входят `.pkg.tar.zst`, `install-genshin-fps.sh`, архив исходников и `PKGBUILD`. Отдельного SHA256SUMS нет.

Проверены локальные тесты, статические проверки, сборка и тест содержимого пакета. Изменение FPS в работающей игре и прохождение переменных через конкретную установку Steam/Proton не проверялись.

### Исправление 0.2.2

Устранена ложная ошибка `ambiguous FPS signature matches`: два валидных вызова функции Genshin Impact могут указывать на одну FPS-переменную. Такие совпадения теперь объединяются; разные адреса по-прежнему вызывают отказ в записи. Исправление подтверждено анализом 20 сигнатур локального PE-файла и модульными тестами. Реальное изменение FPS в игре ещё не подтверждено.
